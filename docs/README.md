## Convenções

- **Deve**: requisito obrigatório;
- **Não deve**: comportamento proibido;
- **Pode**: opcional;
- **Planejado**: ainda não implementado;
- **Experimental**: sujeito a mudança na série.

Mudanças devem atualizar README, API pública, exemplos, critérios de aceite e changelog no mesmo conjunto.
