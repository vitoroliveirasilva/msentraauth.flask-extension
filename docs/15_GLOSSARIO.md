# Glossário

- **Access token:** credencial para API protegida;
- **Application factory:** função que cria a app Flask;
- **Authorization Code Flow:** fluxo web baseado em redirecionamento;
- **Callback:** endpoint que recebe a resposta do provedor;
- **Claims:** atributos validados da identidade;
- **Confidential client:** aplicação server-side capaz de proteger credencial;
- **Consent:** autorização para scopes;
- **Identity:** representação normalizada do usuário autenticado;
- **MSAL:** Microsoft Authentication Library;
- **Nonce:** valor de proteção OpenID Connect;
- **Scope:** permissão de API;
- **State:** valor que associa e protege o fluxo;
- **Storage:** backend de persistência da extensão;
- **Tenant:** diretório Microsoft Entra;
- **Token cache:** estrutura de contas e tokens gerenciada pelo MSAL.
